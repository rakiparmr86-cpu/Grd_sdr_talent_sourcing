# voice_corpus

Drop the campaign's best real outreach here — one file per example (`.md` / `.txt`):
winning cold emails, LinkedIn notes, case-study one-liners, a short tone guide.

The Copy agent (step 2.3) will index these and retrieve the closest few when
drafting, so generated messages sound like GRD and never invent claims.

Keep it small and curated (10-30 strong examples beats 300 mediocre ones).
No customer PII.
